# mushroom

给自己用的法兰西岛蘑菇「可食 vs 有毒」易混对训练器（中英双语，覆盖华人"老家经验"迁移风险）。练的是眼力，不是"可以吃"的许可——吃之前必须当面鉴定。

- [产品 plan](docs/product-plan.md)
- [调研笔记](docs/research-2026-10.md)
- [`scripts/inat_stats.py`](scripts/inat_stats.py)：从 iNaturalist 拉取候选物种在法兰西岛 / 全法的记录数、可用照片数和月分布，输出到 [`data/inat_stats.json`](data/inat_stats.json)

```bash
python3 scripts/inat_stats.py > data/inat_stats.json
```

吃了蘑菇不舒服：巴黎中毒中心 01 40 05 48 48（24 小时）；昏迷或呼吸困难打 15 或 112。
